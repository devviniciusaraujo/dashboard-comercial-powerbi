# 📊 Dashboard Comercial - Power BI

## Sobre o Projeto

Dashboard desenvolvido no Power BI com objetivo de analisar o desempenho comercial através de indicadores de vendas, receita e lucratividade.

## Tecnologias utilizadas

- Power BI
- DAX
- Modelagem de Dados

## Indicadores (KPIs)

- Receita Total
- Lucro Total
- Quantidade de Pedidos
- Ticket Médio

## Análises realizadas

📈 Evolução da Receita ao longo do tempo

📊 Receita por Categoria

🏆 Top 10 Produtos por Receita

🌎 Receita por Região

💹 Lucro por Categoria

## Objetivo

Transformar dados comerciais em informações estratégicas para apoiar a tomada de decisão.
